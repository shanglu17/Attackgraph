# AMS 数据归属与攻击传播（2026-10-20）

同一对软件与控制器之间，清单转换曾同时生成 `Derived data ownership`（按数据编号或描述推断的归属）和 `Data via | SI.4`（接口关联的加载连接）。两条关系被视为平行传播边，造成相同入口、节点序列和分数的一跳路径出现两次。不同 edge_id 只能证明记录不同，不能证明它们代表两个独立的攻击通道。

## 生效规则

清单转换版本仍为 `do356a-ams/v1`，传播投影版本为 `do356a-ams-propagation/v2`。该投影用于正式的“已保存模型”AMS 分析，不改变原 AnalysisService 的遍历、目标筛选或 DPS 评分公式。

- 自动推断的数据归属只表示关联，不证明可传播。关系记录、UUID、业务编号及描述仍保存在核心模型中，但不进入 DPS 图；即使没有实际加载连接，也不能用归属关系补出通道。
- 有明确接口关联的加载/通信连接继续参与遍历。两个独立接口生成的平行连接继续保留，不能把相同节点序列的所有路径直接合并。
- 新导入的关系附带 `analysis.relationship_kind=data_ownership|propagation`。已保存的旧 v1 模型仅在同时带有 `auto_generated`、`do356a-ams/v1` 标签且描述以 `Derived data ownership | ` 开头时适配为归属关系。手工连接、其他导入规则和 `core-dps/v1` 不按描述猜测语义。
- `dps_enabled=false` 仍排除对应连接。原接口方向和信任等级不在本次修正范围，自动连接仍需人工核对。

这是保守的传播证据规则：数据归属不足以单独支持可达性。路径数量减少表示移除了未经通道证据支持的遍历，不能解释为系统风险已下降。

2026-10-20 已对当前已保存模型逐项复核：23 条被排除关系全部有保留接口连接覆盖，三跳范围独立节点路线均为 7,384 条，未发现因该排除丢失的路线。该结论不等于执行或信任依赖已经建模完整，也不能推广到缺少接口关联的新清单。详见 [逐项核对与计算对照](ownership-review.md)。

## 版本与历史

新运行在配置快照、输入快照和映射快照中记录 `propagation.version` 与 `excluded_relations`（业务编号及排除原因）。AnalysisRun 内部记录 `projection_version`，摘要查询无需读取大快照即可判断规则版本。AMS 模型摘要纳入投影版本与排除记录，通用核心模型的摘要格式不变。

旧 AMS 正式运行缺少当前投影版本时，正式摘要和详情标记已过期，禁止导出为当前成果；旧结果、原始输入快照及其哈希不重写。旧兼容读取保持原 DTO 与过期判断语义，浏览器提交完整图的旧分析接口不受此规则影响，也不能作为正式的当前结果。

更新后重启后端、刷新页面，在“图谱分析”重新运行即可；已有模型无需重新导入或删除连接。重用旧 command_id 仍返回原幂等回执，重新分析须使用新的命令编号（界面自动生成）。冻结或归档修订仍遵守原有只读约束。

## 验证

回归测试覆盖旧 v1 数据、新显式语义、归属单独存在、真实平行通道、手工同名连接、其他转换规则、显式禁用、原始模型不变和相同通道评分一致。

本地九表联动清单复现中，自动推断的归属关系为 23 条：参与分析的边由 107 降至 84，所有一跳路径由 247 降至 180。截图对应的同一 `AUTO-CTL` 入口到增压/温控控制器的四条路径变为两条，每个控制器保留一条 SI.4 加载路径，保留路径原始分数均为 0.49。相对归一化分数是另一字段，不能与原始分数混同。

后端 90 项单元测试与构建通过。独立 Neo4j 验收 3 项通过，覆盖核心关系保留、真实通道运行、快照内规则记录、旧版本摘要与详情过期、禁止当前导出及历史快照不变。数据库测试只使用 17687 端口，未向业务数据库写入；本次未修改前端，也未进行浏览器尺寸验收。
