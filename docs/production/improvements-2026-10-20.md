# 项目管理与历史加载验收（2026-10-20）

在原工作目录、原分支实现，没有创建新分支、临时 worktree 或提交；没有修改开发端口。用户已有的 outputs/、tmp/ 未处理。本轮没有操作原7687业务库的项目数据；数据库和浏览器变更均使用独立17687验收库。

## 完成范围

* 页首项目管理：范围预览、编号及原因确认、归档、移入回收站、恢复；项目版本校验、幂等回执及审计。
* 项目列表默认只显示活动业务项目，可查看历史样例、归档和回收站；同名项目显示编号及UUID前缀，管理区显示完整项目与当前修订UUID。
* 分页查询历史摘要、按选择加载一次运行、显式加载完整输入；恢复先前选中的历史摘要，切换运行清除旧路径选择；兼容完整历史接口和导出保持。

操作与接口见 [项目管理说明](project-management.md)。删除是可恢复的回收操作，未提供物理清库；冻结基线及审计保留。

## 仍有的边界

所选一次运行的全部路径仍约3.2MB，本轮没有做路径级分页或逐路径评分详情接口。项目级写入锁保证归档与修订操作一致，会串行化同项目的写入；未开展多修订高并发压力测试。高级研究工具的旧兼容读取语义保留，未整体重构。旧依赖审计项不属于本次修复。历史演示项目只做显示筛选，没有自动清理。

复现：按 [独立数据库配置](README.md)设置测试环境，执行 npm run build、后端/前端单元、test:integration、test:workbench:integration，再依次运行 verify-workbench.mjs、verify-workbench-context.mjs、verify-project-management.mjs、measure-workbench.mjs 和 measure-history.mjs。浏览器脚本位于 apps/frontend/scripts/，要求 ASTRA_TEST_DATABASE=1 和独立本地后端。
