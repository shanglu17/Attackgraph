# 从系统资产清单到报告

1. 在页首创建项目（例如 `AMS-001`）或选择已有项目和修订。确认状态为可编辑。被冻结的修订只允许查看。
2. 打开“数据导入”，下载空模板或填写示例，并选择已经核对的转换适用范围。其他机型或未确认资料会给出诊断，不生成 AMS 模型。示例是文件下载，不会自动写库。将文件上传后，依次核对解析结果、服务端诊断和模型预览。诊断显示原始 Sheet、Excel 行号、字段及编号；空行不会改变定位。
3. 将原始记录与转换资产、自动连接、自动威胁候选、推断目标分别核对。AMS 专用规则必须符合当前资料。点击“提交保存”，成功后点击“检查模型”。
4. 在“图谱分析”点击资产或节点查看属性、来源和关联候选威胁。运行前查看实际目标。最大跳数与衰减采用原算法范围。点击“运行 DPS 分析”，再点击排名条目，检查高亮的节点与连接。
5. 展开评分解释：入口可能性、复杂度、来源权重与专家修正组成入口启发值；逐边因子与跳数衰减组成结构分数；两者相乘得到原始分数，按批次最大原始分数归一化。分数用于相对排序，不代表实际攻击成功概率。
6. 进入“变更管理”，开始编辑资产、连接或候选威胁参数。草稿切换工作区后保留，刷新可恢复。先查看字段前后差异，再执行服务端校验和保存。删除对象不会自动删除引用；悬空引用会阻止提交。
7. 若出现版本冲突，刷新服务端数据并检查相对最新版本的差异。用户可放弃草稿，或明确确认基于最新版本重新校验。系统不会自动覆盖他人的修改。未保存草稿不能参与正式分析。
8. 保存成功后，旧分析保留为历史并标记过期。回到图谱分析重新运行。
9. 打开“报告中心”，核对输入版本、当前版本、映射版本和计算时间。只有模型、配置及参数全部匹配的完成运行才可导出。导出前服务端再次校验当前性。
10. JSON 包含模型、来源定位、配置、算法输入快照、参数、路径和解释；Excel 包含路径汇总、逐跳明细、评分解释和运行信息。历史运行可查看，本轮不提供历史文件导出。

没有路径、运行失败和超时分别显示。无路径只表示本次配置的跳数和范围内未发现路径；Failed 运行保留诊断，禁止作为无路径结论。

工程追踪、受控审查、影响分析和研究方法位于报告中心的高级入口，首次导入与分析不需要填写审批字段。
