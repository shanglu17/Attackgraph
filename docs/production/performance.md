## 原基线及可比边界

基线从 Git 的 `43df6f8` 重新导出和构建，未使用脏工作区或 Demo 体积。旧应用首屏默认图谱、未加载模型时请求 JS 440784 / Gzip 133247 字节；旧页面首次读取同一填写示例后累计请求 870318 / 276325 字节。旧报告/工程页操作后仍为 440784 / 133247。详细模块、实际网络与零写入记录见 [baseline-network.json](evidence/baseline-network.json)。

旧默认图谱与新空导入页工作量不同，首屏数字不能单独证明全部优化。正式已有模型冷图谱、正常 Excel 读取、高级工具均独立记录。旧高级页与正式高级工程审查功能范围不同，不据此宣称相同比例提速；也未比较数据库执行时延。

## 已知限制

已有模型场景包含两个 1984 条路径的历史运行。当前接口一次读取完整历史及输入快照，API 响应约 6.75 MB；JS 拆包没有解决这一开销。后续可将运行列表和详情分离、分页读取，但本轮未改变既有查询语义。这里只报告体积及实际请求模块，没有声称端到端速度、移动设备性能或任意规模模型吞吐已经优化。
